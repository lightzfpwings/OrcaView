## Obtaining and rebuilding the libraries

The a43 source ZIP contains the Qt, Open Babel and interpreter sources. The FFmpeg builds have their own source links in the table. Open the source archives inside it to read the copyright information specific to each component, including each Qt module's LICENSES directory and its third-party sources. The Qt WebEngine module archive contains the code for the Designer and PDF image-format plugins included in the wheels. The platform bundles contain no QtWebEngineCore library or Chromium web engine executable.

The optional interface extensions include standard-control translations from the same Qt 6.8.3 distribution. [Qt translation sources](https://download.qt.io/archive/qt/6.8/6.8.3/submodules/qttranslations-everywhere-src-6.8.3.tar.xz)

The Qt runtime libraries are dynamically loaded. In the macOS application the frameworks are in `Contents/Frameworks/PySide6/Qt/lib`. Rebuilding with `packaging/macos/OrcaView.spec` incorporates the Qt libraries from the build environment and ad-hoc signs the resulting app. The Windows EXE carries its runtime as an embedded ZIP. Its `python/Lib/site-packages/PySide6` directory contains the bindings and Qt libraries. The Windows build recipe can be used to package replacements. On Linux they are under `python/lib/python3.13/site-packages/PySide6`, including the `Qt/lib` subdirectory. You may replace the libraries with ABI-compatible builds, rebuild the bindings, or debug modifications to the libraries. The project build recipe and dependency checksums are in `packaging/desktop/`. Qt source archives include upstream build instructions. [Qt for Python build instructions](https://doc.qt.io/qtforpython-6.8/building_from_source/index.html)

ORCA is an external application with its own licensing and installation procedure. The portable packages do not contain its executable or the Multiwfn engine.

The real ORCA output fixtures retain the program's upstream credits, trademarks and citation notices. The repository's MIT license covers OrcaView's contributions.
