# GaussView 6 功能对照与 OrcaView 交互设计

设计修订 `interaction-design-1`，2026-11-12。实现基线仍为软件 `0.1.0a1`、架构 `prototype-1`、项目 schema 1；分析方向继续采用 `analysis-design-2` 的内部 Multiwfn 来源 Fortran 核心。本轮更新功能范围与交互要求，不增加已实现能力。

## 1. 对照结论与证据

OrcaView 当前具备结构查看、基础输入生成和保守输出摘要，距离完整建模与分析工作台仍有明显差距。原框架已经规划了编辑、轨迹、振动、谱和表面，真正需要补充的是这些能力之间的操作闭环、对象关系和验收条件。Multiwfn 核心提供数值能力；建模、选择、结果导航、比较与任务派生由 OrcaView 负责。

参考来源为 Gaussian 官方 *GaussView 6 Help*（G1）：<https://gaussian.com/wp-content/uploads/dl/gv6.pdf>。以下为压缩的功能导航，页码为手册印刷页，不复刻其界面或素材。本次通过搜索服务核对官方索引正文；直接下载遇到站点挑战页，未获得可用的本地 PDF。下面的 OrcaView 规格均为本项目的设计选择。

| 参考编号 | GaussView 6 参考点 | G1 印刷页 |
|---|---|---|
| G-A | 元素/片段构建入口 | 1 |
| G-B | 模型组与多个视图 | 4 |
| G-C | 角度/二面角修改时选择移动对象并确认或取消 | 27 |
| G-D | 沿正常模正负位移并保存结构 | 113 |
| G-E | 多谱混合、能量与权重管理 | 124 |
| G-F | Cube、表面与映射表面分开管理 | 133 |
| G-G | 扩展选择与选择编辑 | 150 |
| G-H | 优化/扫描坐标编辑与无效项提示 | 169 |

ORCA 的实现依据另行使用其官方手册：几何优化 §4.1、Surface Scans §4.2、IRC §4.4、NEB §4.5（O1：<https://www.faccts.de/docs/orca/6.1/manual/>）。GaussView 的 Gaussian 专用语法不进入 ORCA 生成器；本项目计划按 ORCA 版本逐项验证。

## 2. 当前实际实现

以下根据源码审查；没有重新执行应用测试或 ORCA 计算。

| 范围 | 实际能力与限制 | 代码导航 |

| 显示与选择 | CPU 球棍投影、标签、旋转/缩放/复位；最多选 2 个原子和测距 | `gui/viewport.py:39–142`；`gui/main_window.py:289–302` |

## 3. 功能差距与纳入决定

“细化”表示原来已经规划能力，但本次增加具体交互；“新增”表示原框架缺少独立对象或明确范围。下面均为待实施要求。

| 能力 | 当前实现 | 原框架覆盖 | 本次纳入或细化 | 阶段 |
|---|---|---|---|---|
| 片段建模（G-A） | 无编辑 | P1 已规划原子/键/片段 | 连接点预览、常用片段/收藏、受控补氢与价态提示；可选几何清理单独标注方法覆盖 | P1 |
| 精确几何编辑（G-C） | 两原子测距 | P1 已规划数值修改 | 固定端/移动端与移动原子集合、预览/确认/取消、一次撤销恢复完整操作 | P1 |
| 选择工具（G-G） | 最多 2 个原子 | 尚无完整选择契约 | 有序点选、框选、按元素/连接片段扩展、保存选择集、原子表同步 | P1 |
| 约束与扫描（G-H） | 无 | P2 已规划约束 | 坐标对象同时支持测量、冻结与扫描；先做一维，二维后续；选点查看实际结构 | P2 / A1 扩展 |
| 计算模板与原文 | 基础子集 | P2 已规划高级输入 | 最近设置/个人模板、逐原子基组/ECP 的独立适配；未知原文不被面板覆盖 | P2 |
| 从结果开始新任务 | 无运行/派生 | P3 已规划本地执行 | 从指定帧创建单点/优化/频率；参数复制与波函数重用分开检查；每次生成新任务 | P2–P3 |
| 一次导入关联结果 | 独立文本摘要 | A1 已规划结果底座 | 检查同次计算的 out/hess/gbw/JSON/轨迹，列出关联证据、缺失项和冲突 | A1 |
| 优化与路径浏览 | 无 | P4 已规划优化联动 | 曲线、帧、步数与收敛表共享导航；扫描/IRC/NEB 使用各自路径语义 | A1 / 后续路径适配 |
| 振动诊断（G-D） | 无 | P4 已规划动画/谱 | 频率/谱/动画联动、虚频筛选、正负位移生成派生结构及新优化任务 | A1 / P2–P3 |
| MO 浏览 | 无 | P5 已规划能级/表面 | 按波函数与自旋确定轨道身份，切换轨道、占据/虚轨道过滤、并排比较与网格缓存 | A1 / P5 |
| 表面管理（G-F） | 无 | P5/A2 已规划场与表面 | 网格、建面场、映射场与显示层独立；支持密度面映射 ESP 和一致比较设置 | P5 / A2 |
| 谱图比较（G-E） | 无 | A1 已规划基础谱 | 多数据集叠加、原始棒谱/展宽曲线、实验数据导入、手动权重及条件具备后的构象加权 | A1 / A4 扩展 |
| NMR 结果工作区 | 无 | 手册清单包含分析族 | 屏蔽值/位移表、原子选择联动、明确参考值；耦合、等效核与谱模拟按数据能力另开 | A3 扩展 |
| 多模型/多视图（G-B） | 单文档/单视图 | 曾主要放在 P6 | P1 就定义对象和稳定 ID；A1/P5 建立比较视图，完善交互仍可后续交付 | P1 / A1 / P5 |

周期体系仍排除。NBO 等外部依赖保持[独立登记](research/MULTIWFN_EXTERNAL_DEPENDENCIES.md)，不能因参考产品提供入口就改称内置能力。Gaussian 专用方法和多层模型不按菜单名称照搬；ORCA 对应能力需要独立需求、数据与输入验证。

## 4. 六个优先完成的操作闭环

### 4.1 从点选到精确修改

依次选择 2/3/4 个原子后显示距离/角度/二面角；选择固定端、移动原子集合和目标数值。预览只产生暂存几何，确认生成一条编辑命令与新修订，取消恢复原状态。是否相连不是测量距离的必要条件。

环结构的移动集合不能只用“断开所选键后取一侧”猜测。环、共线三原子、未定义二面角、约束冲突和无法确定移动集合时，给出具体原因并允许明确选择。几何清理、补氢和立体化学操作都要可撤销；有限元素/力场支持范围由适配器说明。

### 4.2 从几何坐标到约束与扫描

同一坐标卡可执行“仅测量”“设为约束”“设为扫描变量”。扫描填写起止值、单位、点数和实际采样值列表；界面统一使用点数，适配器负责转换为目标 ORCA 语义。先支持经验证的一维分子距离、角度和二面角扫描；二维扫描明确显示点数乘积和任务规模。

原子稳定 ID 在生成输入时映射为 ORCA 索引。导出前检查删除/重排、重复变量、冲突约束及目标版本。结果中的每一点保存实际坐标值、帧和收敛状态；缺失点保留缺口，不插值为已计算数据。

### 4.3 从虚频到新的候选结构

频率表、棒谱/展宽谱和动画共享模态身份。动画幅度和速度只控制显示，不修改平衡几何。用户选择模态后可显式创建正/负位移候选结构，记录原模态、位移定义、幅度、单位和源几何，再创建新的优化任务。

位移结构是候选初猜，不自动命名为反应物/产物或已验证极小点。模式正负号由特征向量约定决定；新结构的身份不依赖“正方向就是某一产物”的假设。

### 4.4 从能级与轨道到表面

轨道表显示表示类型、自旋、原始编号、能量和占据；排序只改变列表顺序。选择轨道后异步取得其网格，再创建正负相位等值面。Canonical MO、自然轨道、局域轨道和 NTO 分别命名。

`GridDataset` 保存数值，`SurfaceSpec` 指定建面场和等值面，`MappedFieldRef` 指定着色场，`ViewState` 保存透明度、相机和显示范围。改变显示阈值可复用已有网格；改变求值网格才发起计算。密度面与 ESP 着色场必须具有可验证的几何、单位和空间对应关系。

### 4.5 从谱图到结构与混合谱

点击棒谱定位实际模态或跃迁；点击展宽峰显示贡献列表，因为一个峰可能包含多个条目。多谱比较明确横纵轴单位、缩放、归一化、展宽定义、宽度和数据来源。实验数据作为独立数据集，不覆盖计算值。

混合谱先支持显式手动权重。使用 Boltzmann 权重前，须确认条目属于可比较构象集合，指定能量类型、温度与简并度并记录来源；能量或条件缺失时不自动计算权重。不同分子的实验混合比例不按构象能量替代。

### 4.6 从结果帧到比较与下一项计算

结果浏览器以任务、数据集和实际几何帧为入口。点击优化步/扫描点/路径点，同步曲线和分子；“从此结构创建计算”冻结该帧为新几何，带父任务与帧引用。选择复制设置时显示实际复制项，旧任务与文件保留。

多个模型可并排或叠合，比较视图可锁定相机、等值面阈值和色标。对齐仅改变显示变换；默认采用保持手性的刚体旋转。RMSD 需明确原子映射与选择集合，能量差需明确参考零点和计算条件；比较结果不能自动解释为结合能或反应能。

## 5. 共用对象与模块边界

下面是拟议对象，不是现有 API；真正持久化时升级 schema 并提供迁移。

| 拟议对象 | 职责与规则 |
|---|---|
| `GeometryRef` | 引用不可变的文档修订/结果帧、原子稳定 ID 与映射；轨道、模态、波函数和分析均绑定它 |
| `SelectionContext` | 文档/修订/帧、有序原子 ID、选择集；跨无映射体系切换时不沿用索引 |
| `GeometryEditCommand` | 参数、固定/移动集合、前后修订及撤销数据；暂存预览与提交分开 |
| `CoordinateSpec` / `ConstraintSpec` / `ScanSpec` | 坐标定义、原子 ID、单位、目标/范围与实际点列表；ORCA 语法由版本适配器生成 |
| `ModelCollection` | 组织独立模型与有来源关系的几何集合；不同构象、路径帧和独立化学体系不混为一类 |
| `DerivedJobRequest` | 父结果/帧/模态、新几何、设置来源和重用条件；不覆盖旧任务 |
| `SurfaceSpec` / `ViewState` | 数值引用与显示参数分开；相机、对齐与动画不是新的科学几何 |
| `ComparisonSpec` / `SpectrumMixtureSpec` | 明确映射、数据选择、能量/温度/权重与显示公共设置 |

建议新增模块 `editing/`、`selection/`、`results/navigation.py`、`results/comparison.py` 与 `rendering/layers.py`；它们调用核心对象和应用服务，不把科学规则散放在 Qt 回调中。`analysis/` 和 Fortran 核心继续负责数值分析；常规 UI 操作不依赖运行 Multiwfn。

## 6. 交互验收与顺序

最高优先级是精确编辑/撤销、共享选择、结果来源和几何引用；随后交付振动诊断、轨道/表面和一维扫描；多谱混合、NMR 专题与更复杂路径视图按数据能力扩展。分析主线仍可直接导入已有计算，不等待本地 runner。

代表性验收：

1. 删除/重排原子后，选择、约束和标注仍指向同一稳定对象；失效项明确处理。
2. 二面角修改时固定集合不动；取消无修改，确认后一次撤销可恢复完整状态。
3. 将分子元素或坐标修改后，旧波函数/振动保留在原几何上，不继续叠加到新结构。
4. 模态或轨道表排序后仍显示正确的原始对象；alpha/beta 不互串。
5. 从优化第 7 步创建任务时，使用第 7 步而非最后一帧；虚频正负位移形成独立来源记录。
6. 振动动画、旋转、对齐和统一色标不改变原始科学坐标、结果数值与输入哈希。
7. 同名或同目录文件仍须检查关联；冲突数据不因文件名前缀相同而自动合并。
8. 缺少扫描点、频率、跃迁或权重所需能量时，保留缺失状态，不能生成貌似完整的科学结果。

本轮只进行了源码/官方资料审查及文档一致性检查；没有实现以上对象、运行 GUI 验收或开展真实 ORCA/Multiwfn 验证。
