# Multiwfn 手册分子分析集成清单

设计修订 `analysis-design-2`，2026-11-12。OrcaView 的分析主线采用可随应用提供的 Multiwfn 来源数值核心，复用 Fortran 算法；周期计算与分析不进入范围。NBO 等额外程序和专有数据依赖单独登记，不混入基础分析能力。

本清单是研发范围与输入要求，不是已实现功能表。软件仍为 `0.1.0a1`、架构 `prototype-1`、项目 schema 1。引擎工程方案见 [内嵌计算引擎设计](../MULTIWFN_ENGINE_DESIGN.md)，条件依赖见 [外部依赖清单](MULTIWFN_EXTERNAL_DEPENDENCIES.md)。

## 分类规则

| 类别 | 含义 | 产品处理 |
|---|---|---|
| 内置候选 | 所需分子数据已具备后，可由复用的 Multiwfn 核心完成计算 | 注册为内部分析功能；逐项库化与验证 |
| 条件数据 | 算法可复用，但还需多态、片段、参考原子、Fock、跃迁或响应数据 | 明确列出缺失数据；满足条件后启用 |
| 外部依赖 | 特定子功能需要 NBO/GENNBO、Gaussian 专门输出或额外可执行程序 | 在独立适配区登记；区分导入数据和启动程序 |
| 排除 | 周期波函数、晶胞、周期图像及相应计算流程 | 不注册、不自动转换为孤立分子 |
| 界面重建 | Multiwfn 的菜单、DISLIN 绘图和外部画图脚本 | OrcaView 自行呈现，不把旧菜单搬入产品 |

“内置候选”不表示免除上游 ORCA 计算，也不表示当前已有共享库接口。普通科学输入来源与某项功能的额外程序依赖分别记录。一个功能族有外部依赖分支，不应因此整族排除；一个算法位于 Multiwfn 源码内，也不代表其输入能由普通 Molden 自动提供。

## 阅读与实施顺序

1. **输入和底层核心**：§2.5/2.6、§6.2 p1138–1140、§6.4/6.5；对应加载、单位、有效核电荷、求值与导数。
2. **首个内置分析**：§3.3–3.6、§3.9.1/.9、§3.11.1/.3、§3.15、§3.16；对应点值、网格、Hirshfeld/ADCH、Mayer/Löwdin-Wiberg、ESP 表面。
3. **积分服务与弱相互作用**：§3.100.4、§3.18、§3.23；保留原积分网格、权重、筛选与 OpenMP。
4. **较重分析**：§3.14、§3.20、§3.22、§3.25/3.26；先把参数和结果从菜单分离，再复用计算体。
5. **专项数据**：§3.21、§3.27/3.28、§3.17；激发态、响应和 NBO 依赖各自建立支持矩阵。

第 4 章作为真实样例与解释材料；应随所开放的方法选择一一对应教程，不把教程命令串当稳定 API。§5.2/5.3 用于原版对照和可选兼容后端，不能替代内置引擎的结构化接口。§5.7 的 Gaussian `cubegen` 仅是可选加速通道，内部 ESP 不因此依赖 Gaussian。

## 科学能力的最小粒度

功能注册应声明几何、primitive、完整基组、占据/虚轨道、自旋、ECP、密度类型、Fock、网格、正常模、激发振幅、参考态/片段和响应张量等能力。缺少 MO 时不得把自动促分子回退作为“真实密度计算成功”；相关自然轨道密度与 SCF 密度分别命名。

每个注册项还须附：实际复用过程、输入限制、输出契约、支持构建、误差/完整性检查、收敛参数及引用。加入设计清单只决定范围，开放按钮必须以真实 ORCA 数据及固定 Multiwfn 构建的数值验收为依据。
